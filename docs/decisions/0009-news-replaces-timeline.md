# 0009 A written daily News replaces the README timeline

Date: 2026-11-16 · Status: accepted · Supersedes in part: [0003](0003-tracking.md) (the README timeline)

## Context

The README's "What happened" block listed raw pull request titles under Today, Yesterday and This week, generated from `git log`. The owner, 2026-11-16: the news should give "a true feeling what happened each day in more detail ... holistic and interesting", not a vague list.

## Decision

- The README carries a **News** block between `<!-- news:start -->` and `<!-- news:end -->`: the two newest days, each told in 2 to 4 plain sentences, then the day's changes grouped by meaning, every pull request still linked.
- Each day has a full page in `docs/news/YYYY-MM-DD.md`: what a person can now do and how to try it, where it is slow or rough, and how it fits the week and the other Barkpark projects.
- Written from merged pull requests, their descriptions and reviews only. A quiet day gets one line. "Merged" is never called "in your hands".
- The block and the pages are generated by the daily news run and never edited by hand. `scripts/readme-timeline.mjs` is removed.
- Pictures stay out of git, as [0003](0003-tracking.md) says.

## Consequences

The README is no longer refreshed by `npm run docs`; it changes when the daily news run opens its pull request.
