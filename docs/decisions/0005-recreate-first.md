# 0005 Recreate first, re-imagine later

Date: 2026-11-08 · Status: accepted · Supersedes in part: [0001](0001-black-box-oracle.md) (own words), [0004](0004-own-repo-and-scope.md) (out of scope)

```
phase 1  RECREATE   every screen, label, size, color, timing = the oracle   ◄── we are here
phase 2  RE-IMAGINE change things on purpose, one decision each, on a 1:1 base
```

## Context

The first hero picture invented parts the oracle does not have (a Grants list, our own mark, our own card text). A copy that drifts on day one is no foundation: every later gate would compare against a guess. fluid-editor matched Squarespace 1:1 before changing anything.

## Decision

Phase 1 recreates the oracle exactly. Layout, sizes, colors, labels, the order of things and their timing all match. Every visible control is built, including Share, Suggested (Add to Slack, Create a routine) and Voice chat. A control that would act outside the page (post to Slack, make a routine, share a link) looks and opens 1:1 but stops there until a decision wires it.

Three things are never copied, and get a plain stand-in of the same size instead: the oracle's code, its mascot and logo art, and its font files. The bot's name is whatever its owner names it.

Phase 2 starts only when the gates read 1:1 for every journey. Each change then gets its own decision.

## Considered

- **Our own look from day one.** Rejected: nothing to measure against, so "done" becomes taste.
- **Copy the art too.** Rejected: it is not ours to ship, and stand-ins of the same size do not move a single box.
