# BarkBot · Monday 16 November 2026

So far today: one pull request. Each bot you make now has its own folder on its computer.

## Bot folders

[#62](https://github.com/FRIKKern/barkbot/pull/62). Since Sunday you can make many bots, but they all worked in the same folder on the same computer. Now:

- A bot made with **Create** asks Barkpark for its own folder when its first conversation starts. The folder is `bot-` plus the first 8 characters of the bot's id, so renaming a bot never moves its folder.
- The Main Bot asks for no folder and keeps working in the computer's shared folder, as before.
- If the chat host on that computer is too old to make bot folders, the message line says "A bot in its own folder needs a newer chat host" and nothing is sent. It is never retried without the folder.

This builds on Barkpark's bot folders, merged on Sunday ([FRIKKern/barkpark#26451](https://github.com/FRIKKern/barkpark/pull/26451)).

## Where it is rough

- Tested against a stand-in Barkpark only; no live turn yet.
- If a computer's chat host loses the ability after a conversation has started, that case is not covered by the new rules.
